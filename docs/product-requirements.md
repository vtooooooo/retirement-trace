# Product requirements

Retirement analysts need to distinguish discrepancies in source systems from confirmed administrative decisions. A synthetic workflow starts at a documented flag, collects evidence and notes, and moves through independent review. Model scores may propose identity candidates. The senior reviewer makes case-level decisions about those candidates. A benefits administrator records administrative resolution after review. An issued or settled ledger entry is an imported fact about a simulated payment. The system provides no contact, entitlement determination, or payment execution capability.

| Workspace | Main activity |
| --- | --- |
| Command Center | Inspect portfolio metrics and the priority queue |
| Identity Resolution | Compare ranked pairs and conflicting features |
| Benefit Discrepancies | Inspect transparent rule flags and source references |
| Evidence Graph | Follow case-specific source, proposed, contradicted, and historical relationships |
| Investigation Intelligence | Compare eligible next actions and their assumptions |
| Case Workflow | Move cases through the state machine and record rationale |
| Model & Operations | Inspect held-out and simulated benchmark results |
| Audit & Governance | Reconstruct decisions and export a case report |

Distinct analyst, senior reviewer, benefits administrator, auditor, and system administrator credentials are available in the synthetic local profile. Actions and limitations are documented in the governance guide.
